# Today Action Center

Todayは機能一覧ではなく、アプリを開いた直後に最初の一操作を決める画面です。最上部には「今やること」を1件だけ表示し、その理由と主操作をセットで示します。

## 優先順位

ブラウザー内に残る状態を先に確認し、その後はServerの共通Projectionが次の順で1件を選びます。

1. 入力途中のDraft
2. 保存失敗後の再試行
3. 結果待ちの判断
4. 後日評価待ちの判断
5. 矛盾している重要な確認
6. Current Factを置き換える候補
7. 重要な通常確認
8. 実行待ちの判断
9. 判断待ち
10. 相談候補
11. 記録開始

Server側の順位は `action_center_projection()` を正本とし、`GET /api/action-center` と `GET /api/today/digest` が同じ結果を利用します。Draftと保存失敗だけはServerから見えないため、Clientが最上位へ差し込みます。

## Draftと保存失敗

記録・相談・判断結果・後日評価・Feedbackの入力途中データは `sessionStorage` に保持します。Draftがあれば「続きを入力する」を最優先に表示します。保存に失敗した場合も本文を消さず、再試行または内容確認へ戻れます。成功応答を受け取った場合だけDraftを削除します。

## 表示理由と延期

すべての主Actionには「結果が未記録」「現在情報を更新する可能性がある」などの日本語の理由があります。内部の状態名やIDは表示しません。「後で」は明日まで、1週間、確認Inboxに残す、から選べます。延期情報は判断やFact本体のLifecycleを変更せず、表示制御用metadataへ保存します。

## Todayから移動した機能

- 現在の真実と更新履歴: 記憶／自分の変化
- 保存前の確認: 確認Inbox
- 判断入力と判断一覧: 判断
- 記憶監査・修復・再解析: 管理の「記憶メンテナンス」

Todayには主Action、記録・相談・確認Inboxの3入口、短い件数、今日の一言、最近の変化だけを通常表示します。

## Actionがない場合

対応待ちやDraftがない場合は「新しく記録する」を案内します。確認候補の全件処理を要求する文言は表示しません。
