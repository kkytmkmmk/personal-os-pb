# Decision Replay

Decision Replay は、過去の判断を「決めたこと」だけで終わらせず、次の判断へ安全に再利用するための読み取り中心の画面です。

## 表示する流れ

判断ごとに、きっかけ、当時の状況、選択肢、提案、決定、理由、実行、結果、後日評価、次回に活かすことを時系列で表示します。記録がない段階は推測で補完せず、「未記録」と明示します。

提案は相談時の参考情報であり、本人の判断とは別に扱います。提案・計画・AIの要約から、本人の判断、理由、結果、満足度を自動作成することはありません。

## 使い方

1. 「判断」を開き、対象カードの「振り返る」を選びます。
2. 流れと根拠を確認します。機微な領域は初期状態で要約表示です。
3. 結果や後日評価が未記録なら、その段階だけを明示操作で記録します。
4. 「この判断について相談する」は相談入力欄に文面を入れるだけです。送信はされません。

根拠は画面下部の折りたたみから原文・抽出元へ遡れます。根拠が足りない項目や推測は、現在の事実として扱いません。

## データの扱い

Replay は既存の `decisions`、`execution_events`、`plans`、`recommendations`、関連 Fact と Evidence を投影するだけで、閲覧時に新しい判断や Fact を作成しません。結果・評価・次回メモは、本人が保存操作をしたときだけ既存の判断更新処理に書き込まれます。
