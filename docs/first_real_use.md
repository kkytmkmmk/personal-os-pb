# 初めて実データを使う前に

Personal OS はローカル優先です。初回利用では、少量の記録から始めて内容を確認してから取込範囲を広げてください。

## Today Action Centerを本番で初めて確認する

自動テストは本番DBを開きません。本番利用時は、前回バックアップから24時間経過していること、または手動バックアップが取得済みであることを確認してから起動します。

1. Today最上部の「今やること」と理由を確認する
2. 確認Inboxを開く
3. 内容と根拠を読んだ1件だけを「正しい」にする
4. 別の1件で「後で」→「明日まで表示しない」を選ぶ
5. ページを再読込し、確定した候補が消え、保留した候補が保留中Tabにあることを確認する
6. 使いにくい点は管理画面の「使い方について気づいたことを記録」へ残す
7. アプリを停止する

最初の確認では、Evidence自動判定、既存記憶の修復、会話の再解析、一括確認は実行しません。

## 1. 起動と状態確認

`tools/start_production.ps1` で起動し、「設定」の運用状態を確認します。SQLite の整合性、直近バックアップ、滞留した解析ジョブを表示します。通常の起動時は、前回バックアップから24時間を超えたときだけバックアップを作成します。

スキーマ更新が必要な初回起動では、更新前にバックアップを作成します。`data/`、添付ファイル、バックアップを削除する前に、必ずアプリを停止して別の保管先へコピーしてください。

## 2. 少量から記録する

最初は、明確な事実を数件だけ記録します。例: 今月の積立額、次の旅行の予定、住居の希望条件です。保存後は「記憶」で抽出結果・根拠を確認し、誤りがあれば訂正または除外します。

人物・健康・金融を一律に確認待ちにするのではなく、本人が明示した十分な根拠がある内容は自動確定できます。一方、推測・曖昧な実取引・矛盾する記録は確認対象のままです。

## 3. ChatGPT エクスポートを取り込むとき

一括取込の前に必ずバックアップを確認してください。ローカルLLMを選ぶと会話本文は端末内の Ollama へ送られます。クラウドへのフォールバックは設定で明示許可した場合だけです。許可しない限り、取込処理が停止してもクラウドLLMへ自動送信しません。

取込直後は、解析ジョブの件数・使用モデル・失敗件数を「記憶ダッシュボード」で確認します。全件を人手で確認する必要はありませんが、低信頼度・矛盾・個人に関係しない候補は訂正キューで確認してください。

## 4. 判断を使い始める

相談の提案は下書きです。本人が選んだ時点でだけ判断として残します。実行後は「判断」から結果と後日評価を記録し、「振り返る」で理由と結果を確認します。次回に活かすことは、自動推測ではなく本人の入力として残します。

## 5. 困ったとき

設定画面の「改善を伝える」から、画面・種別・状況・期待する動作をローカルに記録できます。外部送信は行いません。必要なら Markdown としてコピーして共有できます。
