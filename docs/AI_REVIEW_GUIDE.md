# Reviewing Personal OS

Start with:

1. `README.md`
2. `ARCHITECTURE.md`
3. `requirements/00_vision.md`
4. `requirements/91_definition_of_done.md`

Main implementation is in `app.py`, `personal_os/`, and `static/`. Tests are
in `tests/`; benchmarks are in `benchmarks/`.

Repository review must use only synthetic examples. Runtime data, exports,
attachments, backups, `.env`, and `.private_terms` are intentionally ignored.
